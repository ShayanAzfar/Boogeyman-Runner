# Boogeyman Runner
## Boogeyman Runner Game: Dodge the torches.

## Description
### Boogeyman Runner game Inspired by the famous offline chrome dinasour game. The Boogeyman have to dodge the all candles.

## How does it works?
### First you will see a START GAME button, you have to click it, after clicking it the game will be started, you have to use your Space key to jump and dodge all the candles to survive, Each candles increases 10 score points, If you collide with any candle the game will stop and you have to start over with fresh score points from 0.

### This game is fully made by simple HTML CSS and JS and it shows everything is possible on the internet!

## Inspiration?
### Inspired by the offline dinosaur game, when your internet is throwing up, so you get to play it on chrome.
